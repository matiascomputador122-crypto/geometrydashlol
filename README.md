 Geometry Dash Lite (Full Level Pack + Sunshine)

A browser-based Geometry Dash-inspired mini game with a level list that includes all classic main levels plus a custom **Sunshine** level.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Controls

- `Space`, `W`, or `↑` to jump
- Click any level card to switch levels
- Press **Restart** to reset the current attempt
